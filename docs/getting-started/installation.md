# Установка и доступность

[Документация](../README.md) → Установка

**Стабильный публичный выпуск пока не опубликован.** На GitHub исходный код не равен готовому установщику: кнопка Download ZIP скачивает код. Пока нет утверждённого EXE в [Releases](https://github.com/ShinozakiAichi/BardForge-Studio/releases), готовая установка для широкой аудитории не объявлена. Разработчики могут [собрать development-версию](../development/building.md).

Если сопровождающий предоставил тестовую сборку:

1. Используйте Windows x64 и файл `BardForge-Studio-Setup-<версия>.exe` из доверенного источника проекта. Проверьте его версию и опубликованную контрольную сумму, если она есть.
2. Выберите язык установщика и папку установки. Установка предназначена для текущего пользователя, без обязательных прав администратора.
3. Запустите BardForge Studio. Node.js и Python для микшера устанавливать не нужно.
4. Выберите «Русский / English» сверху и откройте [первую сцену](first-scene.md).

Тестовые EXE пока не подписаны сертификатом издателя. Это не основание отключать защиту Windows; сначала проверьте источник файла. ARM64, Linux и macOS пока не заявлены поддерживаемыми платформами.

## Необязательные компоненты

В «Приложение и компоненты» можно подготовить изолированный Python: программа загружает его с python.org, проверяет SHA-256 и запуск, умеет продолжать частичную загрузку. Системные Python и PATH не меняются. Для обычного микшера эта загрузка не нужна. Каталога AI-моделей и установки рабочих расширений через менеджер ещё нет; встроенный Python не предназначен для ручного pip.

## Обновление и удаление

Development-сборки не получают стабильные релизы автоматически. Для стабильных версий реализованы проверка GitHub Releases при запуске и каждые шесть часов, полная загрузка обновления и предложение установки после остановки звука и сохранения. Самостоятельного перезапуска во время игры нет. Доставка между двумя опубликованными версиями **NOT VERIFIED**, поскольку релизов ещё нет.

Удаление приложения сохраняет библиотеку. Перед сменой сборки сделайте [экспорт важных сцен](../user-guide/scenes.md). Development- и стабильная версии используют разные каталоги данных.
