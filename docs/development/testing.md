# Проверки

[Документация](../README.md) → Проверки

После [установки зависимостей](building.md):

```sh
npm run lint
npm run format:check
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:transport
npm audit --audit-level=moderate
npm audit --prefix services/relay --audit-level=moderate
npm run check:licenses
npm run check:public
```

Unit-тесты проверяют модели/хранилище/форматы и ограничения. Playwright — пользовательские сценарии в отдельном браузерном профиле. Транспортная проверка передаёт синтезированный звук между контекстами Chromium; это не проверка настоящего Foundry или удалённого TURN.

На Windows после упаковки:

```sh
npm run test:desktop
npm run test:installer
```

`test:installer` устанавливает EXE в отдельную тестовую папку, проверяет файлы и сценарии, затем удаляет тестовую установку. Он отказывается работать при уже установленном или запущенном BardForge. Для реальной сетевой загрузки Python задайте `BARDFORGE_TEST_DOWNLOADS=1`; без неё нельзя утверждать, что скачивание проверено этим запуском.

Для документации проверяйте ссылки, команды, названия элементов и реальные состояния приложения. Для изменения форматов данных нужны совместимость и восстановление; для аудио — сигнал и прослушивание на целевом оборудовании. `check:public` ищет запрещённые пути и известные формы секретов, но не доказывает отсутствие любых конфиденциальных данных в истории Git. `check:licenses` проверяет прямые распространяемые зависимости, а не права на произвольные медиафайлы.

CI не заменяет [ручные условия выпуска](../releases/README.md). Непроведённые проверки обозначайте **NOT VERIFIED**.
