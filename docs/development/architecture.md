# Архитектура

[Документация](../README.md) → Разработка

Core обеспечивает пригодный для самостоятельной работы локальный микшер и общую инфраструктуру. Модули добавляют отдельные возможности; аудиодвижок не должен дублироваться в каждом модуле. Это граница развития, а не утверждение о готовности всех менеджеров Core.

| Сейчас     | Реализация                                                                                |
| ---------- | ----------------------------------------------------------------------------------------- |
| Desktop    | Electron, sandboxed renderer, context isolation и узкий preload IPC                       |
| Интерфейс  | React + TypeScript, RU/EN, темы и плотность                                               |
| Аудио      | Web Audio + HTMLAudio, групповой микшер, общий системный выход                            |
| Данные     | IndexedDB для сцен и аудио; локальные настройки языка, внешнего вида и последовательности |
| Перенос    | `.bardforge`, лимиты размера, SHA-256 и импорт с новыми идентификаторами                  |
| Компоненты | Изолированная загрузка закреплённого Python; каталога рабочих модулей/AI пока нет         |

`src/components` — UI, `src/useStudio.ts` — операции со сценами, `src/audio` — воспроизведение, `src/storage` — хранение/пакеты, `electron` — десктопные функции. Основной Foundry-код развивается [отдельно](../integrations/foundry.md).

Публичного общего Plugin SDK, нативного аудиодвижка, SQLite, глобальных горячих клавиш, маршрутизации устройств и полного Workspace Manager пока нет. Изменение движка/хранилища потребует миграции данных. Профессиональная низкая задержка не измерена.
