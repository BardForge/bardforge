# Звуковая панель

[Документация](../README.md) → Звуковая панель

Каждая дорожка текущей сцены автоматически появляется плиткой внизу. Нажмите плитку, чтобы запустить звук; повторное нажатие ставит его на паузу. «Стоп» в нижней панели останавливает сцену и сбрасывает позицию. Режим «Один раз / Зациклить» меняется в параметрах дорожки.

Фильтры «Все» и названия верхних категорий показывают соответствующие дорожки, включая вложенные группы. Кнопка «Добавить аудио» импортирует новую дорожку; отдельного редактора произвольных плиток пока нет.

## F1–F12

Первые 12 дорожек сцены доступны по F1–F12. Номер виден на плитке. Фильтр панели не перенумеровывает клавиши. После удаления дорожки порядок может измениться — ориентируйтесь на подписи.

Это **локальные**, а не глобальные горячие клавиши: окно приложения должно быть активно. При вводе текста или выборе значения в поле клавиши не запускают звук. Сочетания с Ctrl, Alt или Meta не обрабатываются как команды панели.

Плитка учитывает Mute/Solo и громкость дорожки и её родителей. Запуск плитки не отменяет отключение звука группы.
