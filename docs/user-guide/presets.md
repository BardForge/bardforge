# Пресеты: что доступно сейчас

[Документация](../README.md) → Пресеты

**Отдельного менеджера пресетов в текущем приложении нет.** Нельзя обещать сохранение отдельных цепочек эффектов или версионируемых пресетов модулей.

Для повторного использования настроек создайте сцену, настройте группы, уровни и режимы дорожек, сохраните её. Затем нажмите **«Копия»** и измените копию для следующей ситуации. Например, из «Ночного леса» можно сделать «Лес перед грозой» с другим балансом музыки и эффектов.

Для переноса между компьютерами используйте [экспорт сцены](scenes.md), который включает аудио. Это шаблон на основе сцены, а не отдельная функция пресетов. Развитие пресетов отмечено в [roadmap](../roadmap.md).
