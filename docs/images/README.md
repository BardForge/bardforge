# Снимки интерфейса

`studio-ru.png` и `studio-en.png` показывают работающий интерфейс `0.1.0-dev.3` в браузерном просмотре при размере 1600×1000. Использован отдельный пустой профиль и встроенная демосцена с алгоритмически синтезированным звуком; пользовательских данных и приватных аудиофайлов нет.

Это снимки текущей реализации, не дизайн-концепты и не подтверждение работы Windows-установщика или Foundry. Встроенная иллюстрация леса создана генератором изображений для проекта; визуальные материалы не включены автоматически в MIT на код. См. [лицензирование](../../LICENSING.md).
