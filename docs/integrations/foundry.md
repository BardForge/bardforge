# Foundry VTT: экспериментальное дополнение

[Документация](../README.md) → Foundry

**Готового подключения Studio → Foundry пока нет.** Установка приёмника не добавляет панель отправителя в Studio. Реальная удалённая сессия, совместимость мира и TURN **NOT VERIFIED**.

Основной репозиторий интеграции — [BardForge/bardforge-foundry](https://github.com/BardForge/bardforge-foundry). Новые изменения приёмника, relay и транспортного SDK направляйте туда. Это транспортный SDK конкретной интеграции, а не будущий общий Plugin SDK BardForge.

- [Администратору: установка, соединение и ключи](https://github.com/BardForge/bardforge-foundry/blob/dev/docs/administration.md).
- [Разработчику: сборка, SDK и проверки](https://github.com/BardForge/bardforge-foundry/blob/dev/docs/development.md).
- [Блокирующая проверка удалённого игрока](https://github.com/BardForge/bardforge-foundry/issues/3).

Код в `modules/foundry`, `services/relay` и `src/transport` внутри Studio пока сохранён для существующих проверок и будущего подключения отправителя. Эти копии не должны развиваться как независимая версия интеграции: исправления транспорта сначала проходят PR в основной Foundry-репозиторий, затем при необходимости переносятся в Core со ссылкой на исходный commit/PR. Удаление копий требует отдельной миграции зависимых тестов и не выполняется в изменении документации.

Локальная работа BardForge не требует установки Foundry. В дальнейшем интеграция должна устанавливаться отдельно; пользовательский менеджер её загрузки ещё не выпущен.
